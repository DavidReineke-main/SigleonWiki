Schattenfresser (Kerzen)
Gewöhnlich
Ernähren sich vom Schatten können dadurch nicht sehr hell leuchten. Geben Licht in einen 3 m Umkreis  verschleiertes Licht in 6 m Umkreis.

___

Glühfarbe
gewöhnlich
hinterlasse Farbe die UV aufnimmt und wenn es dunkel wird erst Sichtbar wird.

___

Zwillingsstein
Gewöhnlich
schreibe in den Stein eine Nachricht sein Zwillingspaar lässt diese Nachricht sichtbar werden.

___

Rufmuschel
Gewöhnlich
Du lässt einen Ton erschallen während du an eine bestimmte Person denkst. Sie und nur sie hört den Ton Mental in ihren Kopf erklingen. Für jeden anderen ist nichts zu hören.

___

Larendel kette
Gewöhnlich
neutralisiert Gerüche für die Person die sie trägt, sie riecht nach Larendel. Im Gegenzug riecht der träger alle Gerüche doppelt so intensiv. 

___
Trank der Heilung
gewöhnlich
Du erhälst Trefferpunkte zurück in höhe der Wertigkeit des Heilungstranks.

| Wertigkeit   | Heilung   |
| ------------ | --------- |
| Gewöhnlich   | 2 W4 +2   |
| Ungewöhnlich | 4 W4 +4   |
| Selten       | 8 W4 +8   |
| sehr selten  | 10 W4 +20 |
___

Giftphiole
gewöhnlich
Kann mit einer Bonus Aktion auf eine Waffe aufgetragen werden. Nächster Angriff der mit dieser Waffe trifft macht zusätzlich Giftschaden.

| Wertigkeit   | Art des Gifts | Schaden, Effekt            |
| ------------ | ------------- | -------------------------- |
| Gewöhnlich   | Vesra Gift    | 2W6 Gift                   |
| Ungewöhnlich |               | 4 W6, Vergiftung DC Kon 14 |
| Selten       |               | 8W6 Incapicitated          |
| sehr selten  |               |                            |
